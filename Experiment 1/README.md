#  Business Analytics

##  Overview

This repository contains my **Business Analytics** work, focusing on data analysis, data transformation, visualization, and extracting meaningful insights from business data.

The project demonstrates how data can be analyzed and presented to support better business decisions.

##  Objectives

- Analyze and understand business data
- Clean and transform raw datasets
- Identify important trends and patterns
- Create meaningful visualizations and dashboards
- Generate insights that can support business decision-making

##  Tools & Technologies

- **Microsoft Power BI**
- **Power Query**
- **DAX**
- **Microsoft Excel**
- **Data Visualization**
- **Data Analysis**

##  Key Operations

The analysis includes:

1. Data Import
2. Data Cleaning
3. Data Transformation
4. Data Modeling
5. Creating Calculated Columns
6. Creating Measures using DAX
7. Data Visualization
8. Dashboard Creation
9. Business Insights

##  Analysis & Visualization

The project focuses on presenting business information through interactive dashboards and visualizations such as:

- KPI Cards
- Bar Charts
- Line Charts
- Pie/Donut Charts
- Tables
- Slicers
- Trend Analysis

These visualizations help identify important patterns and make the data easier to understand.

##  Key Learning Outcomes

Through this project, I gained practical experience in:

- Business data analysis
- Data cleaning and transformation
- Power BI dashboard development
- Power Query operations
- DAX calculations
- Data modeling and relationships
- Data visualization
- Converting raw data into meaningful business insights
